Why Inzx

Everything a music app should have.
Nothing it shouldn't.

No subscriptions, no ads, no account gate and no telemetry — just a fast, gorgeous Material 3 player built on a native InnerTube engine.

Word-level karaoke lyrics, synced to the syllable

Powered by the BetterLyrics TTML engine with smart fallback across 15+ providers. Tune line and word offsets, see instrumental gaps and background vocals, and translate or transliterate any line live with your own AI key.

I'm try- na put you in the worst mood, ah
Je veux te mettre dans la pire des humeurs, ah
BetterLyrics TTML LRCLib Genius Musixmatch KuGou Megalobiz YouTube captions Embedded & local

Studio-quality audio

Stream from YouTube Music's native InnerTube engine or switch to the JioSaavn HQ source for up to 320 kbps. Gapless playback, crossfade and prefetching keep every skip instant.

Gapless Crossfade Prefetch Prefer audio versions

0 ms dynamic theming

An isolate-based palette extractor pulls colours straight from the album art and caches them, so the whole UI re-themes the instant a track starts. Material 3, 10+ accents, or pick your own from the wheel.

Four Now Playing styles

Default, Cinematic, Ripple and OG — each with linear, waveform or spectrum scrubbers, animated Canvas album art and ambient glow reflections.

Jams — listen together, live

Host a real-time room over Supabase WebSockets. Everyone shares one queue they can edit and reorder, playback stays in sync with drift correction, and the last controller wins.

Host & guest roles Shared queue Drift correction

Your whole library, synced

Pull in YouTube Music playlists, likes, albums and artists, mix them with local files organised by folder, and take anything offline with the background download manager.

Playlists Local folders Downloads Podcasts

Android Auto & widgets

A native Android Auto dashboard for the road, compact 4×1 and expanded 4×2 home-screen widgets, full media-session controls, and smart audio routing that shows the live output device.

Android Auto Home widgets Smart routing

Private by default, offline by design

Inzx is offline-first and stays usable without a connection. Credentials live in encrypted secure storage, tracks and palettes are cached locally with Hive, and there is no third-party analytics or telemetry anywhere in the app. Updates arrive as instant Shorebird patches — no reinstalls, no stores.

No analytics Encrypted credentials Offline-first Backup & restore MIT licensed

Under the hood

Flutter, tuned for audio

A custom InnerTube engine, isolate-powered colour extraction and over-the-air patching — the whole stack is open for you to read.

Core & state

Flutter and Dart with Riverpod for state, Hive for a fast local cache of tracks, playlists and palettes, secure storage for credentials, and Supabase driving real-time Jams.

Flutter 3 Riverpod Hive Supabase Shorebird OTA

Audio & catalog

A hand-written InnerTube API client feeds just_audio and audio_service for background playback, media session and Android Auto, with audio_session handling focus, calls and Bluetooth.

For developers

Build it yourself

Flutter stable, Android SDK and Git is all you need. Jams and Google Sign-In are optional — everything else runs without them.

Clone

git clone https://github.com/nirmaleeswar30/Inzx.git

Install dependencies

flutter pub get

Generate code

dart run build_runner build --delete-conflicting-outputs flutter gen-l10n

Configure env

cp .env.example .env

Run or build

flutter build apk --split-per-abi --release
