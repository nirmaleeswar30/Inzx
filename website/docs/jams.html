Jams

A Jam keeps everyone's playback in sync: same song, same moment, on everyone's phone.

Start or join

You need to be signed in. Open Jams from the menu, then Start a Jam to get a code, or enter a friend's code to join. You can also share a Jam link: anyone who opens it lands straight in your Jam.

Who controls playback

The host controls playback, and can give any participant control too. People with control can play, pause, seek, skip and edit the queue. The host's player is the source of truth: after anyone with control changes something, the host confirms the new state so every phone ends up the same.

The Jam queue

Everyone sees the shared queue in Up Next. When it runs low, the host's radio tops it up.
