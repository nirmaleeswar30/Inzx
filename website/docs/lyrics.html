Listening

Lyrics

Inzx searches several lyric providers and picks the best synced version it can find.

Kinds of lyrics

  • Word-synced: each word lights up as it's sung, karaoke style.
  • Line-synced: the current line is highlighted and the sheet scrolls along.
  • Plain: unsynced text, when nothing better exists.

Following along

The sheet glides to each new line just before it's sung. Scroll by hand to read ahead; it picks up again after a few seconds, or tap Auto-scroll. Tap any line to jump there.

AI translation

Turn on AI lyric translation from the lyrics menu (⋯) to show a translation under each line.

Wrong or out-of-sync lyrics

From the lyrics menu you can pick a different provider, or nudge the timing offset if lines run early or late.

Something wrong or missing? Open an issue on GitHub.
