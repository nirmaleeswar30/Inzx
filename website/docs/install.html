Getting started

Install & update

Inzx runs on Android, iOS, Windows, and Linux. It is free and open-source, with no ads or trackers.

Android

  1. Open the latest release on GitHub.
  2. Download the APK for your phone (ARM64-v8a for modern devices, or Universal if unsure).
  3. Open it and allow installation from your browser or file manager.

Stay updated automatically: Add Inzx to Obtainium to track new releases and update seamlessly.

Install from the Inzx source

  1. Set up SideStore or AltStore Classic using its installation guide.
  2. Once the IPA is available, open Sources, choose Add Source and paste https://inzx.nirmaleeswar.dev/altstore.json. Open in SideStore · Open in AltStore Classic
  3. In Browse, search for Inzx and tap Install. Your sideloading app downloads and signs the IPA.

Once available, you can also get the IPA from GitHub Releases and import it manually. Download the current IPA

Updating and refreshing on iOS

Use the same sideloading app to install new IPA versions. Free Apple Accounts usually need to refresh their signature every seven days. Shorebird builds can receive Dart fixes in the app. Native changes and bundled assets require an updated IPA.

What to expect on iOS

YouTube uses AAC rather than Opus/WebM. Lossless add-ons support FLAC/ALAC and compatible DASH streams. iOS manages the audio output mixer, so there is no bit-perfect switch or CarPlay support yet. Jams and Inzx Connect stay connected while music plays or the app is open, then reconnect when you return.

Windows

  1. Download Inzx-Setup-<version>.exe from the latest release on GitHub.
  2. Run the installer. It installs per-user (no administrator permissions required) into %LOCALAPPDATA%\Programs\Inzx.
  3. A desktop shortcut and start menu entry will be created. The in-app updater keeps it upgraded silently in the background.

Linux

  1. Download Inzx-<version>-x86_64.AppImage from the latest release on GitHub.
  2. Make the AppImage executable: 
    chmod +x Inzx-*-x86_64.AppImage
  3. Run it directly. On first launch, you will be prompted if you'd like Inzx integrated into your desktop application menu.

The AppImage carries its own libmpv and audio decoders for bit-perfect playback without touching your system's global mpv config.

In-app updates & Shorebird OTA

Builds made with Shorebird can receive over-the-air (OTA) patches on Android, iOS, Windows, and Linux; restarting applies a downloaded patch. Standard Flutter builds need a new APK, IPA, or desktop installer. On iOS, install new IPAs through your sideloading tool or the AltStore/SideStore source; the app cannot replace itself. Refreshing your Apple ID signature is still required even with OTA patches.

First launch & pairing

The first time you open Inzx you get a quick welcome flow. You can Continue with Google to bring your YouTube Music library, playlists, and history in, or Continue without signing in. You can also pair multiple devices via Settings → Inzx Connect for synchronized playback. See Signing in and Integrations.
