Getting started

Install & update

Inzx runs on Android. It isn't on the Play Store, so you install the APK yourself.

Download

  1. Open the latest release on GitHub.
  2. Download the APK for your phone. If you're not sure which one, pick the universal APK.
  3. Open it and allow your browser or file manager to install apps when Android asks.

Stay updated with Obtainium

Add Inzx to Obtainium and it will notify you about new releases and install them straight from GitHub.

In-app updates

Inzx also checks for updates itself. Small fixes arrive as silent patches: when one has downloaded you'll see a banner asking you to restart. When a full new version is out you'll see a banner with a download link, and after updating a short "What's new" sheet.

First launch

The first time you open Inzx you get a short welcome. On the last page you can Continue with Google to bring your YouTube Music library in, or Continue without signing in. Everything except your library, history sync and Jams works without an account. See Signing in.
