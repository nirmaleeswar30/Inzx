v1.5.8 Latest Release Android · Windows · Linux
Shipped · v1.5.8

Desktop Port (Windows & Linux), Inzx Connect & Listening Stats

Major milestone expanding Inzx to native Windows and Linux desktops with bundled libmpv playback, multi-device bidirectional playback sync via Inzx Connect, and personal listening statistics.

  • Windows & Linux Desktop: Native Windows installer (.exe) and Linux AppImage with global media keys, SMTC / MPRIS, and background self-updater.
  • Inzx Connect: Bidirectional multi-device pairing, synchronized playback, and remote playback control.
  • Listening Stats: Detailed listening analytics, top tracks & artists breakdown.
  • Desktop Shorebird OTA: Over-the-air code push updates across Windows, Linux, and Android.

v1.5.4 Lossless & Automix
Shipped · v1.5.4

Lossless & Hi-Res Audio, DJ Automix & AutoEQ Calibration

Flagship audio overhaul featuring studio-master 24-bit / 192 kHz lossless playback, intelligent DJ beat-matched automix transitions, and AutoEQ parametric headphone calibration.

  • Lossless & Hi-Res FLAC: Custom renderers delivering 24-bit / 192 kHz playback with bit-perfect passthrough.
  • DJ-Grade Automix: Neural tempo and harmonic key analysis for automatic, seamless transitions with zero dead air.
  • AutoEQ Headphone Correction: 5,000+ headphone calibration profiles ported from LastWave and Jaakko Pasanen's database.

v1.5.0 Jams & RPC

Real-Time Jams, Discord Rich Presence & Home Screen Widgets
