Lossless & Hi-Res Audio, DJ Automix & AutoEQ Calibration

Flagship audio overhaul featuring studio-master 24-bit / 192 kHz lossless playback, intelligent DJ beat-matched automix transitions, and AutoEQ parametric headphone calibration ported from LastWave.

  • Lossless & Hi-Res FLAC: Custom ExoPlayer renderers delivering 24-bit / 192 kHz playback with bit-perfect DAC passthrough.
  • DJ-Grade Automix: Neural tempo and harmonic key analysis for automatic, seamless transitions with zero dead air.
  • AutoEQ Headphone Correction: 5,000+ headphone calibration profiles ported from LastWave and Jaakko Pasanen's database.
  • Core Modernization: Build optimizations, Android launcher widget polish, and playback stability improvements.
